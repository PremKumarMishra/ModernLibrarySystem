# Modern Library Management System

A sophisticated, high-performance desktop application designed for modern libraries. This system combines a **premium JavaFX UI** with a robust **SQLite** backend to provide a seamless experience for managing books, members, and staff.

## 🚀 Key Features

* **Rich Modern UI:** Designed with a 10/10 visual aesthetic, featuring glassmorphism, smooth transitions, and a dark-themed (#121212) professional dashboard.
* **Comprehensive Data Management:** Efficiently handles Books, Members, and Librarians using a structured SQLite3 database.
* **Real-time Statistics:** Instant visual feedback on total stock, issued books, and active memberships directly on the dashboard.
* **Recent Updates Feed:** A live log of the latest transactions and inventory changes to keep track of library flow.
* **Automated Overdue Reminders:** Integrated feature to identify overdue books and send reminders to members, ensuring timely returns.
* **Search & Filter:** Advanced querying capabilities to find any record in seconds.

## 🛠️ Tech Stack

* **Language:** Java
* **Framework:** JavaFX (with custom CSS for premium styling)
* **Database:** SQLite3
* **Architecture:** MVC (Model-View-Controller)

## ⚙️ Setup & Installation

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/PremKumarMishra/ModernLibrarySystem.git
    ```
2.  **Database Configuration:**
    * Ensure `sqlite3` is installed or use the provided `.db` file in the App folder.
    * The application automatically initializes tables on the first run.
3.  **Run the Application:**
    * Open the project in your favorite IDE (IntelliJ IDEA recommended).
    * Ensure JavaFX SDK is configured in your project structure.
    * Run the `Launcher.java` file.
